# Diario Inglés

Editor de texto tipo diario para escribir mis experiencias en inglés y
practicar gramática. Un botón revisa la última oración, explica los errores
y permite escuchar cómo suena la versión corregida.

## Tecnologías
- Python, Flask
- SQLAlchemy + SQLite
- LanguageTool (corrección gramatical)
- JavaScript y Web Speech API (lectura en voz alta)

## Cómo correrla
​```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
flask run
​```
